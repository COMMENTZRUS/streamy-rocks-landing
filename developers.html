Local Stack Quickstart

Streamy OS is a Node.js 20+ monorepo paired with a native Kotlin Android TV Leanback shell and MIT Solidity / Anchor payout splitter contracts. Boot all services and run the full 57-test suite locally in under a minute:

bash · streamy-os quickstart 
npm install
npm run dev:all           # Boots all 8 Streamy OS microservices (:5101–:5108)
npm run dev:proof-stack   # Boots Panorama proof lane (:4010 / :4011)
npm test                  # Runs all 57 workspace tests
npm run test:shared       # Runs shared JWT auth & security tests
npm run smoke:e2e         # End-to-end playback + proof + settlement smoke

Core Living-Room, Ad & Payout Endpoints

Mutating internal endpoints require either a scoped Bearer JWT (Authorization: Bearer <token>) or x-streamy-key.

Dual-Chain MIT USDC Payout Splitters

Streamy OS settles strictly in USDC (6 decimals) across both Solana (native to Panorama Protocol with zero bridging) and Ethereum / Base. Both implementations are clean-room MIT-licensed Constant-Time Splitters (O(1) deposits & withdrawals) with remainder-preserving accounting that eliminates dust-griefing.

Solana · SPL USDC (Anchor 0.30.1)

Path: contracts/payout-splitter-solana/
Uses a single PDA-owned standard SPL USDC vault (no Token-2022 transfer hooks), checked u128 math (1e18 RPS scale), and two-step Squads multisig admin transfer.

  • Mainnet USDC: EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v
  • Devnet USDC: 4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU

Ethereum & Base · ERC20 USDC (Solidity 0.8.27)

Path: contracts/payout-splitter/
StreamyAdminSplitter, StreamyERC20Splitter, and EIP-1167 StreamySplitterFactory. Verified by 6/6 Cancun EVM audit tests (1e30 scale, SafeERC20, ReentrancyGuard, EIP-712 setSharesMultiMeta).

  • Ethereum USDC (1): 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48
  • Base USDC (8453): 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913
bash · verify & deploy splitters 
# Run Solidity 0.8.27 Cancun EVM audit regression tests (6/6 passing)
cd contracts/payout-splitter && npm install && npm test

# Deploy EVM factory + 80/20 protocol USDC splitter (set SPLITTER_OWNER_ADDRESS to your Gnosis Safe)
npm run deploy:base-sepolia
npm run deploy:base

# Build & deploy Solana SPL USDC splitter (transfer upgrade authority to Squads multisig)
cd ../payout-splitter-solana
anchor build && anchor keys sync && anchor build
anchor deploy --provider.cluster mainnet

Android TV Shell & Hardware Security Model

apps/streamy-tv-shell/android-tv is a native Kotlin Leanback launcher powered by Media3 ExoPlayer. By design, the streaming stick never stores wallet private keys, RPC endpoints, or transaction signing code. Creators manage dual-chain USDC splits and claims on streamy.rocks/dashboard/revenue, while the stick only displays read-only summaries via PayoutSummaryClient.kt.

bash · build & install Android TV debug APK 
cd apps/streamy-tv-shell/android-tv
./gradlew :app:assembleDebug \
  -PSTREAMY_DEBUG_GRAPH_URL="http://10.0.2.2:5101" \
  -PSTREAMY_DEBUG_EDGE_URL="http://10.0.2.2:5103" \
  -PSTREAMY_DEBUG_PAYOUTS_URL="http://10.0.2.2:5104"
./gradlew :app:installDebug

Shipped TV Modules

HomeBrowseFragment.kt (multi-row catalog + Cast poller + idle screensaver), PairingActivity.kt (QR activation), SearchActivity.kt (Leanback search), PlayerActivity.kt (WebVTT CC toggle, resume & 10s autosave, Ad Pod HUD, Up Next countdown), and PayoutSummaryClient.kt.

Release & FCC Bring-Up Rules

Release APKs strip master service keys (PANORAMA_EDGE_SERVICE_KEY="") and authenticate via per-device JWTs minted during QR pairing. WebVTT Closed Captions (C.TRACK_TYPE_TEXT) ship enabled by default for FCC CVAA readiness.
